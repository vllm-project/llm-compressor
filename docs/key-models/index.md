# Key Models

The following models are among the most commonly used with LLM Compressor: DeepSeek V4 Flash, Qwen3.8-27B, Qwen3.8-2.4T-A95B, Qwen3.8-Flash-Next, Kimi-K3, Gemma 4, Llama 4, Mistral Large 3, HY-V3, GLM-5.3, and GLM-5.3-Flash. Each model page contains quantization examples with tested configurations and recommended parameters.
