🎯 WHAT IS LAYERWISE DECOMPRESSION?
─────────────────────────────────────────────────────────────────────────────

PROBLEM:
  Recalibrating 100B+ model normally requires:
  → Full decompression into FP32 (100+ GB)
  → Process everything at once
  → OOM errors on most hardware ❌

SOLUTION:
  Process one layer at a time:
  1. Decompress layer N (1-2 GB)
  2. Recalibrate with fresh data
  3. Recompress layer N
  4. Move to layer N+1
  
  Peak memory: 60-70 GB (not 100+ GB) ✅

❓ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

OOM Error?
  • Reduce NUM_CALIBRATION_SAMPLES to 64
  • Reduce MAX_SEQUENCE_LENGTH to 512
  • Add sequential_offload_device="cpu"
  → See TESTING_LAYERWISE.md for full guide

Calibration hangs?
  • Test with 1 sample first
  • Check dataset loads: python -c "from datasets import load_dataset; ..."
  • Verify model loads: python -c "from llmcompressor.modeling.kimi_k3 ..."

Bad model outputs?
  • Check ignore patterns are set correctly
  • Verify moe_calibrate_all_experts=True
  • Ensure propagate_error=True
  → See TESTING_LAYERWISE.md for details
